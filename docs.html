快速开始

从注册到看到第一条告警,通常不超过 5 分钟。以下指南适用于演示环境与自托管部署。

01三步接入

  1. 注册账号在注册页创建账号,系统会自动为你生成一套演示数据与专属控制台。
  2. 接入数据源选择流量镜像、eBPF 探针或云端只读 API 三种方式之一,对业务零侵入。
  3. 开启自动处置在控制台「处置剧本」中启用预置剧本,引擎将按触发条件自动响应。

02本地部署

项目为纯 Node 实现,无原生依赖,克隆后两条命令即可运行:

$ git clone https://github.com/qwq-nm/nexus-security.git
$ cd nexus-security && npm install
$ npm start
# → http://localhost:3000  (SQLite 数据库位于 data/nexus.db)

纯静态托管(GitHub Pages 等)会自动进入浏览器演示模式,无需后端。

03API 参考

所有接口均需会话 Cookie(登录后自动携带),返回 JSON。以下是常用端点:

端点说明
POST/api/auth/register注册账号并初始化演示数据
POST/api/auth/login登录(每 IP 10 分钟限 8 次)
GET/api/bootstrap一次性拉取控制台全部数据
GET/api/presence当前在线分析师列表
POST/api/alerts/:id/action处置告警:ban / isolate / ignore / resolve / unban / release / reopen
POST/api/alerts/batch批量处置(仅 resolve / ignore)
POST/api/alerts/simulate注入一条模拟告警(红队演练)
POST/api/playbooks创建自定义处置剧本
PUT/api/auth/profile更新称呼与公司信息
PUT/api/auth/password修改密码(校验旧密码)
GET/api/export/alerts.csv导出告警 CSV(带筛选参数)
GET/api/streamSSE 实时事件流

04示例:拉取并处置一条告警

$ curl -c cookies.txt -X POST localhost:3000/api/auth/login \
    -H "Content-Type: application/json" \
    -d '{"email":"demo@nexus.sec","password":"demo1234"}'

$ curl -b cookies.txt -X POST localhost:3000/api/alerts/ALT-10247/action \
    -H "Content-Type: application/json" \
    -d '{"action":"ban"}'
# → {"ok":true,"feed":{"level":"ok","msg":"告警 ALT-10247 来源 IP 已封禁…"}}.
